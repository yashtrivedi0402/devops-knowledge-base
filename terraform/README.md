# 🌍 Terraform Knowledge Base

Welcome to the **Terraform** section of my DevOps Knowledge Base.

This module documents my journey of learning **Infrastructure as Code (IaC)** using Terraform—from the fundamentals to production-ready infrastructure automation.

Rather than memorizing commands, the focus is on understanding **how Terraform works internally**, **how infrastructure is managed declaratively**, and **how Terraform is used in real-world DevOps workflows**.
